# Third-party components

Runtime inference stays in Rust/native code. The call-scoped helper is an owned
subprocess; no separate installed application or service is required.

- `vendor/nemo-speech`: NVIDIA NeMo-Speech.cpp, Apache-2.0. Source revision recorded in `vendor/pins.json`; copyright, LICENSE, NOTICE and THIRD_PARTY_NOTICES retained. `native/diar_api.cpp` is an exact standalone diarization extraction from the pinned `c_api.cpp`, with its original exception/status boundary. `scripts/extract_diar_abi.py --check` verifies it. The local CMake builds only diarization/encoder/frontend/common/runtime dependencies, avoiding ASR SentencePiece/protobuf conflicts with static ONNX Runtime. Local patches set `DiarSegmentationCfg` to published NeMo bypass postprocessing (0.5, no pads/minimum duration/gap filling), restore the checkpoint's serialized bf16 Hann coefficients, and add an opt-in frontend feature dump.
- `vendor/ggml`: the pinned NeMo llama.cpp submodule's ggml subtree, MIT; LICENSE retained. Only the CPU/Metal backend source directories are retained and statically linked; Metal shader embedded. Other backend build options are unsupported in this macOS crate. NVIDIA's CUDA-only patch series is not used on this Mac.
- `vendor/opus`: Xiph reference source at 7b05f44f4baadf34d8d1073f4ff69f1806d5cdb4, BSD-style license in COPYING; copied from the audiopus_sys 0.2.2 source distribution. A CMake minimum-version-only change permits CMake 4. The distribution lacks release version metadata, so `opus_get_version_string` says `libopus 0`; the source revision, not that string, identifies the codec. It is used by offline QA, not an always-running codec service.
- ReDimNet2-B6 ONNX weights: MIT, upstream large-margin vb2+vox2 revision. License retained in `vendor/ReDimNet-LICENSE`; weights are ignored and pinned by the fetch script and runtime SHA check.
- Nemotron 3 Diarization weights: OpenMDW-1.1, separate from the native code license. Model card and exact artifact source recorded in docs/speakers.md and the download receipts. Weights are ignored.
- Sortformer v2.1 Core ML weights: FluidInference conversion of NVIDIA four-speaker Sortformer, CC-BY-4.0. Immutable model revision and every compiled file SHA-256 are in scripts/bakeoff-sources.json and sortformer-manifest.json. Weights stay ignored.
- Sortformer streaming cache algorithm: adapted from FluidAudio (FluidInference), Apache-2.0, revision e560c6445ffdc42e60c7b282d162aae271f18e2a; its NeMo-derived attribution applies. License retained in `vendor/FluidAudio-LICENSE`. The public cache updater supplies an independent Swift golden fixture, and CPU PyTorch supplies the mel frontend fixture. No Swift runtime dependency is shipped.
- Community-1 QA export: aufklarer/Pyannote-Community-1-CoreML, CC-BY-4.0; original pyannote Community-1 attribution retained in its downloaded LICENSE. Immutable export/source/host revisions and every artifact hash are recorded in scripts/bakeoff-sources.json and community1-manifest.json. The QA adapter uses pyannote.audio (MIT) host algorithms and compares the soniqo/speech-swift native host (MIT). Neither the Python host nor Community-1 weights are bundled in the app.
- ONNX Runtime / ort, SHA-2, serde, hound, rustfft and objc2: their upstream Rust/runtime licenses apply. No separate ONNX Runtime dylib is loaded.
- AMI public audio/annotations: retain corpus/annotation attribution and sources in docs/speakers.md and local download receipts. No corpus audio is committed. Only compact scalar calibration fixtures are shipped.

The crate performs no Discord API requests, bot integration, client injection or permission requests.
