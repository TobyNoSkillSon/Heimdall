# Parakeet vocabulary biasing

The Metal Parakeet TDT decoder biases a short list of names toward their spelling and can penalise pieces of
languages the user does not speak. It changes token choice before the prediction network consumes the token; it never
rewrites a finished transcript.

Read this when: you want to add or remove a biased word, a name keeps being misheard, the transcript drifts into
another language, or you are changing the decoder's bias tables.
Code: `crates/listen/src/vocabulary.rs`, `crates/listen/src/default-vocabulary.json`,
`crates/listen/src/public-vocabulary.json`, `crates/listen/src/foreign-pieces.json`, `crates/app/src/identity.rs`
(`asr_words`).

## The word lists

- Personal edition: `default-vocabulary.json`, 20 entries. Entries may be phrases (`T3 Code`).
- Public edition (`public` feature): `public-vocabulary.json` (Heimdall, Claude, Codex, T3 Code) and no language
  prior (penalty 0). A test checks the public list holds none of the personal words.
- Personalise: when the assistant's name is not Heimdall, it is added at the next model load
  (`vocabulary::set_extra_words`, called from `identity::publish`), within the 128-entry bound. Changing the name
  reloads the speech models (`identity::Change::asr`).

## Change the list

1. Edit `crates/listen/src/default-vocabulary.json` (or `public-vocabulary.json`).
2. Keep each entry valid: letters and digits, words separated by single spaces, at least one letter, at most 64
   characters. No apostrophes or hyphens. At most 128 entries and 1,024 distinct prefix nodes.
3. Words of two or three letters get no completion flag, no completion bonus and no joined-word split; prefer longer
   words.
4. A word stays only if it repairs mentions and changes no ordinary control text. Score it with
   `lab/listen/scripts/score_vocabulary_list.py` on new `heimdall-listen-file --whole` receipts (mentions repaired,
   controls changed).
5. Check: `cargo test -p listen vocabulary` (validation, edition lists, completed-span rendering).

Words tried and kept out because they changed controls or were ambiguous: `threads`/`thread`, `DeepSeek`,
`spindump`, `Grok` (confused with Groq), `Sol`, `Kimi`, and broad `Va`/`Vi`/`Hi + dall` entries.

## Override at startup

- `HEIMDALL_ASR_VOCABULARY`: a JSON array of words; it replaces the list (include `Heimdall` to keep it). An empty
  array is the unbiased control.
- `HEIMDALL_ASR_VOCABULARY_BOOST`: finite, 0 through 8. Default 4.0.
- `HEIMDALL_ASR_FOREIGN_PENALTY`: finite, 0 through 16; 0 disables the prior. Default `DEFAULT_FOREIGN_PENALTY`
  (6.0), 0 in the public edition.
- `Parakeet::set_vocabulary(Vocabulary { words, boost, foreign_penalty })` applies on the next decode without
  reloading. The recognizer keeps the configuration across GPU recreation and recovery.
- The app's worker, lazy replay and backend swaps all build through `Parakeet::load_backend`, which reads the
  environment. There is no vocabulary menu setting.

## Language prior

Parakeet v3 takes no language input and drifts into its other languages on accented or short speech. The bias table
subtracts `foreign_penalty` from every piece English and Polish never produce (`vocabulary::foreign`):

- any letter outside the English and Polish alphabets (Cyrillic, Greek, ä/é/š…);
- 530 word-initial Latin pieces only other languages use (`foreign-pieces.json`), generated by
  `crates/listen/scripts/foreign_pieces.py` from frequency lists, exempting every prefix of a common English or
  Polish word or a word from a folder of English technical writing, so ` var`, ` seg`, ` vec` stay free.

It applies in every prefix row, never touches blank, and never penalises a piece on a configured vocabulary path. It
is a penalty, not a mask: a foreign piece still wins when it leads by more than the penalty. Limit: a foreign word
respelled from shared pieces (Dutch ` da` + `ar` for `daar`) is not caught.

## Decoder behaviour

- `Vocabulary` builds a case-insensitive prefix automaton over the model's 8,192 SentencePiece tokens
  (`TOKEN_COUNT` 8,193 with blank). Each prefix row holds the next state and an additive logit bonus. The resident GPU
  decoder reads the row inside its token-decision kernel, with no extra dispatch or host readback.
- Bonuses at the default boost 4.0: an exact word-start piece of at least two letters gets `boost × 0.25` (1.0); an
  observed sound-alike entry start gets `boost × 0.5`, capped at 2.0; a continuation gets `boost` (4.0), and one that
  completes a configured word of at least four letters gets `boost × 2` (8.0). Single-letter starts, contraction and
  incomplete entry fragments get no bonus; the `Al` entry is admitted without a start bonus.
- Word starts need a SentencePiece boundary. An unfinished path may cross a boundary (`Hi Mdal`, `Nemo Tron`).
- A mismatched token resets the prefix. Blank keeps it, but a prefix expires more than eight encoder frames after the
  last emitted token (640 ms at 80 ms per frame). Each encoder window starts fresh.
- Blank gets no bonus. When blank wins acoustically, bias may override it only with a token that completes a
  configured word. Confidence is computed from the original acoustic logits, so bias cannot inflate it. The duration
  decision, ten-symbol frame guard and token guard stay in force.
- Sound-alike entries are the explicit `ENTRIES` table in `vocabulary.rs` (for example `Hi`/`Hem`/`Him`/`I'm`/`Hi'm`
  into Heimdall, `Qu`/`Ku` into Qwen, `tifri` into T3 Code). Heimdall paths also accept the `dahl` ending. The rest of
  the word must still decode; no edit-distance or phonetic search runs over transcripts.

## Rendering

- Completed spans render with the configured capitalisation. A span joins its pieces, keeps the first start and last
  end time, and takes the lowest original token confidence. Failed or expired paths keep their original text.
- A phrase is matched without spaces (` T` `3` ` Co` `de` → `t3code`) and rendered as one word per phrase word,
  sharing the span's time by character count.
- A following joined alphabetic token is split off (`Heimdallbug` → `Heimdall bug`), unless the joined tail is an
  ordinary suffix (`s`, `es`, `ed`, `d`, `ing`, `er`, `ers`, `est`, `ly`, possessive `'s`): `har` + `ness` + `e` + `s`
  renders `harnesses`, `Heimdall` + `s` + `ystem` renders `Heimdall system`. An explicit SentencePiece boundary always
  starts a new word.

## Limits

- Table size: `prefix_nodes × 8193 × 8` bytes (4-byte state, 4-byte bonus) on both host and GPU, plus a small GPU
  prefix state. Entry spellings count toward the node total.
- The Core ML recovery backend sees only the joint model's chosen token, not its logits: it keeps the list and the
  rendering but does no biasing until the Metal path returns ([inference-engine.md](inference-engine.md),
  [resilience.md](resilience.md)).
- Not measured: Polish name recognition, the cost of long lists, live command-trigger recall, the Core ML path. A
  single-word list measured a median +0.07 ms per decode on Apple Silicon.
